# Style explorer

Goal: widen the choice, then narrow. Same product, same facts, different looks. Brand colours, logos and rules come from the project; a style changes the composition, type and texture, never the facts or the logo.

## Steps
1. Read the project's brand rules and its approved templates. Note what already exists so you don't repeat it.
2. Pick 5 styles from the list that are **far apart** from each other and from the approved ones. Explain each one in one line.
3. Render 5 stills of the same content (one product, one title, the same facts). Use the project's studio or library if it has one. A new style is a new building block (for example a new background, layout or pattern file), not a one-off hack.
4. Show them side by side and ask which to keep, mix or drop. Then make a video version of the picked ones (follow `motion-design`).
5. Once a style is approved, the user promotes it to a template or recipe. Never do that yourself.

## Style menu
| Style | Look | Good for |
|---|---|---|
| Editorial | big serif headline, lots of white space, small product, thin rules | premium, doctors |
| 3D glass | frosted panels, soft light, product floating | tech, new arrivals |
| Minimal mono | one colour plus white, one line of text | clean feeds, quotes |
| Bold type | huge sans words fill the frame, product cut in | offers, launches |
| Clinical | grid, labels with callout lines, spec table | pro audience, education |
| Gradient mesh | soft multi-colour blobs, glow | stories, lifestyle |
| Paper and collage | torn paper, tape, hand marks | behind the scenes, tips |
| Dark premium | near-black, rim light, gold or chrome accent | hero products |
| Swiss grid | strict columns, numbers, flat colour blocks | carousels, guides |
| Playful sticker | rounded shapes, emoji-like icons, tilt | patient and parent audience |

## Rules
- Contrast: text at least 4.5:1 against its background.
- At most 2 fonts per post. Respect the account's colour family (for example a pastel account stays pastel).
- Each example changes one big thing at a time when refining; changes many things when exploring.
- Batches of 5. Send each batch as soon as it is done.
