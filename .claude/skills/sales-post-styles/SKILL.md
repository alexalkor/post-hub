# Sales post styles

General craft only. **Brand voice, facts, banned words, logos, prices and approvals always come from the project** (its `CLAUDE.md`, brand files, fact sheets). If the project has a post studio or building-block library, build the format from those blocks; do not invent a parallel system.

## How to use
1. Read the project's rules first. Note soft rules (prices, faces, competitors) and keep them on unless the request switches them off.
2. Pick 3 to 5 formats from the table that fit the goal (awareness, consideration, sale) and the audience (pro / B2B vs consumer).
3. For each, give: format name, hook line, layout sketch (what sits where), the motion if it is a video, and the caption angle.
4. Make examples first (stills), let the user pick, then build the final. Never skip to the final.

## Formats
| Format | Goal | Hook pattern | Layout | Notes |
|---|---|---|---|---|
| Product spotlight | consideration | "Meet X: <one key benefit>" | big product, 3 short fact pills, name card | Facts from the fact sheet only |
| New arrival | awareness | "New: X" / "Now in stock" | "NEW" label, product on clean background, 1 line why it matters | Label colour matches the theme |
| Offer / sale | sale | "<offer> until <date>" | price or offer block large, product smaller, clear end date | Only with prices the owner supplied; say the soft rule is off |
| Expert tip | trust | "Tip for <audience>: ..." | numbered tip, small product in corner | Pros get detail; consumers get plain words |
| Myth vs fact | trust | "Myth: ... / Fact: ..." | two-part split, cross vs tick | The fact must be checked |
| Comparison (own range) | consideration | "Which X is right for you?" | 2 to 3 products side by side, 1 line each | Never name competitors unless allowed |
| Before / after (diagram) | result | "How X works" | schematic or illustration, not a patient photo | No faces without written consent; no promised results |
| Carousel / guide | saves | "5 things to know about ..." | cover slide plus 1 idea per slide plus a CTA slide | Same theme across slides |
| Countdown / launch | urgency | "3 days to ..." | big number, product teaser | Only real dates |
| Testimonial / quote | trust | "<short quote>" - role | quote card, role not full name | Real quotes with consent only |
| FAQ | consideration | "You asked: ..." | question large, answer in 2 lines | Pull questions from real DMs if available |
| Behind the scenes | brand | "How we ..." | warehouse, packing, training, events | No identifiable people without consent |

## Hooks that sell without hype
- Lead with the benefit to the reader, not the product name.
- Be specific: a number, a material, a time saved. Vague claims are weak.
- One idea per post. If you need two, make a carousel.
- Soft close (CTA): "Ask us for the catalogue", "Link in bio", "DM for samples". Never pressure, never promise results.

## Variety
Rotate format, layout, background and motion so no two posts in a row share more than one of them. Keep a short log of what ran recently if the project has a plan file.
